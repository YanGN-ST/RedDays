Automatically updated calendar subscriptions for mainland China statutory holidays, Hong Kong public holidays, lunar dates and other calendars.

## Subscribe

In macOS Calendar, choose **File → New Calendar Subscription** and paste a URL. Alternatively, replace `https://` with `webcal://`.

| Calendar | Subscription |
|---|---|
| Mainland holidays, detailed | `https://yangn-st.github.io/RedDays/reddays-detailed.ics` |
| Mainland holidays, minimal | `https://yangn-st.github.io/RedDays/reddays-minimal.ics` |
| Makeup workdays | `https://yangn-st.github.io/RedDays/reddays-workonly.ics` |
| Lunar dates and solar terms | `https://yangn-st.github.io/RedDays/reddays-lunar.ics` |
| Daily almanac | `https://yangn-st.github.io/RedDays/reddays-almanac.ics` |
| Hong Kong, simplified / traditional | `https://yangn-st.github.io/RedDays/reddays-hk.ics` / `https://yangn-st.github.io/RedDays/reddays-hk-tc.ics` |
| Ethnic festivals | `https://yangn-st.github.io/RedDays/reddays-ethnic.ics` |
| Hijri dates | `https://yangn-st.github.io/RedDays/reddays-hijri.ics` |
| Christian calendar | `https://yangn-st.github.io/RedDays/reddays-christian.ics` |

The detailed mainland feed lists each holiday day and makeup workday. The minimal feed lists the first holiday day and makeup workdays. The workday feed contains makeup days only. Ordinary weekends are omitted. Workday events include a time and reminder.

## Sources and limits

Mainland and Hong Kong holidays follow their respective official notices. Lunar and solar-term dates use astronomical calculation. Ethnic festivals draw on local sources, and Islamic festivals may differ by a day when official moon-sighting announcements differ from calculation. The daily almanac reflects folk traditions and is for reference. The Christian calendar follows Western ecclesiastical calculation. Events include source notes where applicable.
